# Sponsor logos

Drop each logo here as a transparent PNG named `<slug>.png`. The
`SponsorsSection` component references these by slug, and each card swaps from
its name placeholder to the image automatically once the file exists.

Recommended: transparent background, ~400px wide, the logo trimmed to its
bounding box (cards apply `object-fit: contain` inside a fixed 80px-tall card).
